# Простий формат INOutFile

Один файл містить один об’єкт `ObjectCosmos`: один рядок із рівно 11 числами через кому.
Без заголовків, дужок, назв полів чи назви типу.

Порядок: `x,y,z,vx,vy,vz,ax,ay,az,mass,radius`.

```text
20,50,120,12,0,0,0,-0.01,0,1000,10
```

Перші три числа — координати, наступні три — швидкість, потім три — прискорення,
останні два — маса й радіус. Десятковий роздільник — крапка; підтримується експоненційний
запис. Значення читаються як `BigDecimal` без перетворення на `double`.
Пробіли навколо чисел та кінцевий перенос рядка дозволені.
Порожні поля, неправильна кількість чисел і кілька записів спричиняють `IOException`.
Фізичні обмеження значень перевіряє валідатор моделі.

`ObjectCosmos` абстрактний, а тип у файлі не записується, тому конструктор приймає
фабрику конкретного об’єкта (`Supplier<? extends ObjectCosmos>`).
Коли реалізовано, наприклад, `Planet extends ObjectCosmos`, використовуйте:

```java
InOut<ObjectCosmos> file = new INOutFile("planet.txt", Planet::new);
file.output(planet);
ObjectCosmos restored = file.input();
```

Фабрика має повертати новий екземпляр при кожному виклику.
Запис замінює файл. Батьківський каталог має існувати. Кодування — UTF-8.
Доступні також `input(Path)` і `output(Path, ObjectCosmos)` для іншого шляху.

JSON-реалізація збережена окремо як `InOutJSON`; її формат описано в [json-format.md](json-format.md).
